# PentaSoul Website

Corporate website for PentaSoul, an independent product-focused technology company.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run typecheck
npm run build
```

## Product URLs

Current products link to configurable placeholders. Copy `.env.example` to `.env.local` and replace:

- `NEXT_PUBLIC_DSMS_URL`
- `NEXT_PUBLIC_LEGALEASE_URL`
- `NEXT_PUBLIC_ROZNAMCHA_URL`
